# 내가 그린 친구 🖍️

아이가 자연사박물관에서 본 동물·공룡이나 스스로 상상한 동물·공룡을 그려 친구로 만들고, 음성으로 대화하며 감정을 나누고 자연 속 미션을 하는 정서 코칭 웹앱입니다. 만 3~5세 유아에 맞춰 친구는 짧고 쉬운 말로 이야기합니다.

## 그림이 직접 움직이기

영상이 없어도 그림 한 장으로 친구가 움직입니다 (시험 기능).

1. **새 친구 만들기**에서 그림과 이름을 넣습니다.
2. 그림에서 **눈 두 곳과 입**을 차례로 누릅니다. 옆모습이면 **눈이 하나예요**, 입을 그리지 않았으면 **입이 없어요**를 누릅니다.
3. 미리보기를 보면서 눈과 입 크기를 맞추고 **만나러 가기**를 누릅니다.

영상을 쓰고 싶으면 같은 화면의 **직접 만든 표정 영상도 넣고 싶어요**를 누릅니다. 넣은 감정은 영상으로, 안 넣은 감정은 그림 움직임으로 보여줍니다. 기본·말하기 영상을 둘 다 넣으면 그림 대신 영상으로 움직입니다.

표정은 신나요, 슬퍼요, 놀라요, 궁금해요, 뿌듯해요, 차분해요, 부끄러워요, 무서워요, 좋아해요 9가지입니다. 영상이 없는 표정은 그림 전체가 종이 인형처럼 움직이고(통통 뛰기, 갸웃하기, 축 처지기, 오들오들 떨기 등), 놀라요에는 느낌표(!), 궁금해요에는 물음표(?)가 머리 옆에 잠깐 나타납니다. 부끄러워요·좋아해요에는 볼 터치, 슬퍼요에는 눈물이 함께 나옵니다. 그림이 늘어나 보이지 않도록 눈·입 변형은 살짝만 씁니다.

대화 화면에서는 그림 전체가 원래 비율 그대로 보입니다.

**내가 그린 친구들**에서 연필 버튼을 누르면 그림과 이름, 눈·입 위치, 표정 영상을 나중에 고칠 수 있습니다.

## 친구 목소리

친구마다 목소리를 다르게 정할 수 있습니다. 새 친구를 만들 때 눈·입 아래에서 고르거나, 연필 버튼 → **목소리** 탭, 또는 대화 화면의 **⋯ 어른 메뉴 → 친구 목소리**에서 바꿉니다.

- **목소리 느낌:** 기본, 꼬마 친구, 아기 동물, 씩씩한 친구, 차분한 친구, 느릿느릿 공룡. 누르면 바로 들려줍니다.
- **태블릿에 있는 목소리:** 기기에 깔린 한국어 음성 중에서 고릅니다. 다른 기기로 옮겼는데 그 음성이 없으면 자동으로 고릅니다.
- **높이·빠르기:** 막대로 세밀하게 맞춥니다. 높이를 올리면 아이 같은 목소리가 됩니다.

## 문제 놀이

대화 화면 위쪽의 **문제** 버튼을 누르면 **내가 문제 내기**와 **문제 맞히기** 중에서 고릅니다.

### 문제 맞히기

친구가 동물 하나를 몰래 떠올리고, 아이가 질문 10번으로 맞힙니다. 카드는 28종으로, 우리 곁 동물(강아지·고양이·토끼·다람쥐·오리·나비·달팽이), 공룡과 옛날 생물, 물에 사는 친구, 땅에 사는 친구로 나뉩니다. 박물관 전시물은 어느 층에서 만나는지도 알려 줍니다.

- 말로 묻거나 질문 버튼을 누릅니다. 막히면 **힌트**, 이름이 떠오르지 않으면 **정답 고르기**를 씁니다.
- 질문을 다 써도 실패로 끝나지 않고 보기에서 고르는 단계로 넘어갑니다.
- 대부분의 질문은 `src/lib/quiz.ts`의 카드 정보로 답하므로 인터넷과 API 사용량이 필요 없습니다. 카드로 답할 수 없는 말만 온라인 AI가 카드 사실을 근거로 답합니다.
- 전시 내용과 다른 부분은 `src/lib/quiz.ts`의 해당 카드를 고치면 됩니다. 질문 수는 `QUIZ_QUESTION_LIMIT`로 바꿉니다.
- 다음 아이가 시작할 때는 문제 맞히기 화면의 **맞힌 기록 지우기**를 누릅니다.

### 내가 문제 내기

아이가 동물이나 공룡을 마음속으로 떠올리면 친구가 질문 10번 안에 맞힙니다.

- 아이는 말로 대답하거나 마이크 양옆의 **네**, **아니요** 버튼, 왼쪽 아래 **잘 모르겠어요**를 누릅니다.
- 온라인 AI를 쓸 수 있으면 어떤 동물이든 맞히려고 합니다. AI가 막히거나 없으면 카드 28종 안에서 질문으로 맞힙니다.
- 친구가 질문 10번 안에 못 맞히면 아이가 고릅니다. **더 물어봐요**를 누르거나 "계속 물어봐"라고 하면 질문을 5번 더 하고, **알려 줄게요**를 누르면 정답을 물어보고 칭찬합니다.
- 아이는 "넹", "네 정말 커요", "날개는 있는데 못 날아요", "아까 말했잖아요"처럼 자세히 대답해도 됩니다. 친구가 뜻을 알아듣고, 이미 대답한 질문은 다시 묻지 않습니다. 온라인 AI가 막혀 카드 질문으로 넘어가도 지금까지의 대답을 이어서 씁니다.
- 친구의 말은 네/아니요 질문 한 문장만 나오도록 걸러 냅니다. AI가 다른 놀이 제안이나 어색한 말을 섞으면 한 번 더 부탁하고, 그래도 안 되면 카드 질문으로 이어 갑니다.

## 자연물 찾기 미션

대화 화면 위쪽의 **미션** 버튼으로 시작합니다.

1. **친구에게 미션 받기**를 누르면 친구가 찾아올 자연물을 말해 줍니다.
2. 아이가 찾아서 **찾았어요!**를 누르고 사진을 찍으면 AI가 확인합니다.
3. AI를 쓸 수 없거나 사용량 제한에 걸리면 **어른이 사진을 보고 확인**합니다. 인터넷이 없어도 놀이를 계속할 수 있습니다.
4. 찾은 자연물은 도장과 함께 모이고 **마음 리포트**(위쪽 ⋯ 어른 메뉴)에도 나타납니다. 미션 목록의 **N장** 버튼을 누르면 그 미션에서 찍은 사진을 모두 볼 수 있고, **오려서 꾸미기**로 바로 스티커를 만들 수 있습니다. 다음 아이가 시작할 때는 **보호자·선생님 설정 → 도장 모두 지우기**를 누릅니다.

- **미션 추가:** 보호자·선생님 설정에서 그날 장소에 맞는 미션을 추가할 수 있습니다.
- **사진 전송:** AI 확인을 켜 두면 축소한 사진이 Groq 또는 Google로 전송됩니다. 아이 얼굴이나 이름표가 나오지 않게 찍고, 전송을 원하지 않으면 설정에서 끕니다.
- **현장 안전:** 식물을 꺾거나 곤충을 잡지 않고, 어른 눈에 보이는 곳에서 활동합니다. 찾은 것을 입에 넣지 않습니다.

## 자연물로 꾸미기

대화 화면 위쪽의 **꾸미기** 버튼이나 **내가 그린 친구들**의 잎사귀 버튼을 누릅니다.

1. **찍기**(카메라), **사진**(갤러리), **미션**(미션에서 찍은 사진) 중 하나로 사진을 고릅니다.
2. 꾸미고 싶은 자연물을 손가락으로 **콕** 누르면 배경이 오려집니다. 잘못 오려진 곳은 **지우기**·**살리기**로 문질러 고칩니다.
3. **흰 테두리** 스위치로 테두리를 넣을지 고른 뒤(기기가 마지막 선택을 기억합니다) **스티커 만들기**를 누르면 스티커가 **자연물 보관함**에 담기고 친구 그림에 붙습니다.
4. 붙인 스티커는 끌어서 옮기고, 두 손가락이나 아래 버튼으로 키우고 돌리고 뒤집습니다. 바꾼 내용은 바로 저장됩니다.

- 그림으로 움직이는 친구는 스티커도 그림과 함께 움직입니다. 영상 친구는 영상 위에 스티커가 겹쳐 보입니다.
- 오리기는 기기 안에서만 하므로 사진이 밖으로 나가지 않고 AI 사용량도 쓰지 않습니다.
- 처음 한 번 **마법 가위**(약 20MB)를 내려받습니다. 와이파이에서 미리 꾸미기 화면을 한 번 열어 두면 그다음부터는 기기에 저장된 것을 씁니다. 인터넷이 없으면 **간단 가위**로 오리며, 종이나 손바닥처럼 단색 바닥 위에 올려 찍으면 잘 됩니다.
- 자연물 보관함은 이 기기의 모든 친구가 함께 씁니다. 보관함에서 지워도 친구에게 붙인 스티커는 남습니다.

## 배포 (GitHub Pages)

마이크·음성인식은 **https 주소에서만** 동작하므로 반드시 인터넷에 배포해서 씁니다.

`main` 브랜치에 올리면 GitHub Actions(`.github/workflows/deploy.yml`)가 자동으로 빌드해서 `https://smc0103.github.io/makemate/`에 배포합니다.

1. 처음 한 번: 저장소 **Settings → Pages → Build and deployment → Source**를 **GitHub Actions**로 바꿉니다.
2. 코드를 고친 뒤 `git push`하면 몇 분 뒤 사이트가 바뀝니다. 진행 상황은 저장소의 **Actions** 탭에서 봅니다.

> 무료 GitHub 계정은 **공개(Public) 저장소**에서만 Pages를 쓸 수 있습니다.

### 예전 방식: Netlify Drop

1. `npm run build` 실행 → `dist` 폴더가 만들어집니다.
2. https://app.netlify.com/drop 에 접속해 로그인(무료 가입)합니다.
3. `dist` 폴더를 화면에 끌어다 놓으면 `https://○○○.netlify.app` 주소가 생깁니다.
4. 코드를 고친 뒤에는 다시 빌드하고, Netlify 사이트의 **Deploys** 탭에 `dist` 폴더를 끌어다 놓아 업데이트합니다.

> API 키는 사이트에 포함되지 않습니다. 각 기기의 설정 화면에서 따로 입력하며 그 기기 안에만 저장됩니다.

## 갤럭시탭 설정

1. **크롬**으로 배포 주소를 엽니다.
2. 크롬 메뉴(⋮) → **홈 화면에 추가**(또는 **앱 설치**) → 홈 화면의 아이콘으로 실행하면 전체 화면으로 열립니다.
3. 처음 마이크 버튼을 누를 때 **마이크 허용**을 눌러 주세요.
4. 자연스러운 목소리: 태블릿 **설정 → 일반 → 글자 읽어주기(TTS)** 에서 기본 엔진을 **Google 음성 서비스**로 바꾸고 한국어 음성 데이터를 내려받습니다. 그다음 앱 **설정 → 친구 목소리**에서 마음에 드는 목소리를 고릅니다.
5. 앱 **설정**에서 Groq / Gemini API 키를 다시 입력합니다.
6. 밖에서 쓸 때는 와이파이나 휴대폰 핫스팟에 연결합니다. 인터넷이 끊겨도 앱은 열리고 오프라인 친구가 대답합니다.

## 친구 옮기기 (노트북 → 태블릿)

1. 노트북: **친구들 보러가기** → 친구 카드의 공유(↗) 버튼 → `친구이름.maeumfriend` 파일이 저장됩니다.
2. 이 파일을 태블릿으로 옮깁니다 (구글 드라이브, 카카오톡 나에게 보내기, USB 등).
3. 태블릿: **친구들 보러가기** → **가져오기** → 파일 선택.

영상은 MP4 또는 WebM 모두 갤럭시탭 크롬에서 재생됩니다.
